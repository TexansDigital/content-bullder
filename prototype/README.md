# Feed prototype

`feed-prototype.html` — single-file, no build step. Open it in a browser.

Three views: the 9:16 in-app player, the 4:5 web rail as it would sit on houstontexans.com,
and the pipeline spec. Built on the Houston Texans design system (Deep Steel / Battle Red,
HelveticaNeueLT Extended, Azeret Mono), fonts and bullhead embedded as data URIs so it runs
offline.

**Real:** the five collections, the interaction model (scroll-snap, keyboard, like, captions,
action button, sponsor slot), both aspect ratios derived from one source, the ten YouTube
Shorts IDs as item identity.

**Placeholder:** the frames and all copy. This environment has no network route to YouTube, so
the footage has not been seen — frames are generated on-brand stand-ins. Real posters drop in
once Cloudinary access lands; the layout and crop are already built to receive them.
